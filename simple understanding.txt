# Smart AI-Powered Service Desk System

## 1. Project Title

Smart AI-Powered Service Desk System using NLP, RAG and GPT-based Ticket Classification

---

# 2. Problem Statement

Organizations receive a large number of support requests related to IT services, HR queries, and Facility Management. Customers often struggle to find answers quickly and support teams spend significant time manually categorizing and handling tickets.

The proposed Smart AI Service Desk System aims to reduce response time and improve customer satisfaction by providing:

* FAQ Search
* AI-powered Knowledge Base Search using RAG
* Automated Ticket Classification
* Ticket Management System
* Agent Dashboard
* Administrative Management Portal

The system enables users to search for answers before creating tickets and automatically routes tickets to the correct department with appropriate priority.

---

# 3. Objectives

### Primary Objectives

* Provide self-service support through FAQ Search.
* Implement AI-powered Knowledge Base Search using RAG.
* Automatically classify support requests.
* Automatically assign ticket priority.
* Enable communication between customers and agents.
* Provide dashboards for support agents.
* Manage users, agents, FAQs, and RAG content through an admin panel.

### Secondary Objectives

* Reduce manual effort.
* Improve ticket resolution time.
* Increase customer satisfaction.
* Improve support team productivity.
